# 3D Bat Shooter

A 3D first-person shooter game built using the **Godot Engine**.

## About the Game

In this game, the player explores a 3D environment, encounters enemies, and uses shooting mechanics to defeat them.

## Features

- First-person player movement
- Camera controls
- Shooting mechanics
- Enemy movement and combat
- 3D environment

## Built With

- [Godot Engine](https://godotengine.org/)
- GDScript


## Controls
 Action
 Move | WASD 
 Look Around | Mouse 
 Shoot | Left Mouse Button 
 Jump | Space
